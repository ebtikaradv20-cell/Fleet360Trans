# Fleet360Trans 🚛⚡

نظام متكامل لإدارة وتحسين عمليات الأسطول لشركة **طاقة عربية**، تم تطويره ليشمل الهوية البصرية الجديدة للمؤسسة، مع توفير لوحة تحكم ذكية وأدوات إدارة متقدمة.

---

## 🌟 الميزات الرئيسية (Key Features)

* **🎨 الهوية الجديدة:** واجهات مستخدم محدثة تتوافق تماماً مع الهوية البصرية الجديدة لشركة طاقة عربية.
* **🔍 الفلاتر المتقدمة (Advanced Filters):** إمكانية البحث والفرز الدقيق للمركبات، السائقين، والرحلات بناءً على حالة التشغيل والبيانات المختلفة.
* **📊 التصدير (Data Export):** دعم تصدير التقارير والبيانات بصيغ متعددة (مثل CSV و Excel) لسهولة التحليل.
* **🌐 نظام اللغات (Multi-language Support):** دعم كامل للغتين العربية والإنجليزية لسهولة الاستخدام من قِبل جميع أفراد الفريق.
* **🧭 توجيه لوحة التحكم (Smart Navigation):** تجربة استخدام سلسة لتوجيه المستخدم والتنقل بين أقسام اللوحة والإحصائيات بمرونة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** [Next.js](https://nextjs.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) / PostCSS
* **ORM & Database:** [Drizzle ORM](https://orm.drizzle.team/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Deployment:** [Vercel](https://vercel.com/)
